# Maria Marcantonio — GitHub Pages Portfolio

This folder is ready to publish as a static GitHub Pages website.

## Files

- `index.html` — main portfolio
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation + simple scroll animation
- `resume.html` — updated web résumé with a **Print / Save as PDF** button

## Publish for free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a new **public** repository named:
   `YOURUSERNAME.github.io`
3. Upload all four files from this folder into the repository root.
4. Commit the files.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then save.
8. Your site will be available at:
   `https://YOURUSERNAME.github.io`

## Before publishing

Review these items in `index.html` and `resume.html`:

- Confirm the current degree/major and graduation year.
- Add your LinkedIn URL if desired.
- Add more detailed Swagelok bullets when available.
- Replace the initials portrait with a professional photo later if desired.

For privacy, the site intentionally does **not** publish your street address or phone number.
